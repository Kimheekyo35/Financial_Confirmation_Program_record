## OPENAI API 비교
- gpt-6-luna와 gpt-5.6-luna 의 성능 비교.

```
response = client.responses.create(
    model = "gpt-6-luna",
    instructions = prompt,
    tools = [{"type": "web_search",
              "filters":{
                "blocked_domains":[
                    "kbank.org"
                ]
              }}],
    input = "골드만삭스 한국지점"
)
```

우선, tools에 web_search가 가능하고 도메인 제한이 가능함. kbank.org의 최신 정보 유무가 확실하지 않고, playground에서 실행했을 때 kbank.org를 많이 참고하여 해당 페이지 접속을 막고 최대한 공식 홈페이지에 참고할 수 있게 제한함.

```
서울특별시 종로구 새문안로 68 흥국생명빌딩 21층
입력토큰: 8,687
출력 토큰: 83
```
위 결과는 `gpt-5.6-luna` 로 실행시켰을 때 나오는 결과.

```
서울특별시 종로구 새문안로 68, 흥국생명빌딩 21층 ([goldmansachs.com](https://www.goldmansachs.com/worldwide/korea/location/?utm_source=openai))
입력토큰: 8,607
출력 토큰: 111
```

위 결과는 `gpt-6-luna`로 실행시켰을 때의 결과물.
