### 서버 메모리 부족

**현재 사용하는 용량 확인**
`free -h`

처음에는 둘이 쓰기 작은 서버인 줄 -> **extensionHost와 Pylance가 여러 세트로** 실행되고 있었음. 현재 사용하고 있는 서버의 메모리 크기는 8GiB임. 

`ps aux --sort=-%mem | head -15` 는 현재 많이 사용하는 메모리의 top 15를 출력한 것

둘이 사용하고 있는 서버의 구조는
```
Azure VM 8 GiB
│
├─ Streamlit 앱 A : 8080
│   ├─ Python
│   ├─ OpenAI API
│   └─ SQL 데이터 로드
│
└─ Streamlit 앱 B : 8501
    ├─ Python
    ├─ OpenAI API
    └─ SQL 데이터 로드
```

하지만 서버가 끊겼을 때 VS Code 안의 터미널도 같이 끊김. 따라서 로컬 power shell에서 `ssh azureserver@공인<ip>` 로 들어가서 확인하면 됨.
그다음 많은 용량을 잡아먹은 pylance를 가볍게 설정해야 함.

`Ctrl + Shift + P -> Preferences: Open Remote Settings (JSON)` 로 들어가서 

```
{
    "python.analysis.languageServerMode": "light",
    "python.analysis.diagnosticMode": "openFilesOnly",
    "python.analysis.indexing": false
}
```

과 같이 설정해주면 됨.
