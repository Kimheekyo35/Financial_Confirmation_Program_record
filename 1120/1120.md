## systemd 적용

적용하게 된 계기는 memory 차지를 많이 해서 streamlit을 vscode와 분리시키는 걸 목표로 함. systemd를 이용하면 vscode를 종료하거나 SSH 연결을 끊어도 앱을 계속 실행할 수 있으며, 설정에 따라 자동 재시작과 부팅 시 자동 실행도 가능함.

우선 `ps -p 1 -o comm=` 를 실행시켰을 때 **systemd** 이면 해당 환경에서 사용 중이라는 뜻. Ubuntu, Linux 환경에서 사용 가능.

### systemd 명령어

보통 `systemctl status <서비스명>` 인데 여기서 서비스명은 .service 파일 이름으로 정해짐.

`sudo nano /etc/systemd/system/address_check.service` 여기서 **address_check.service** 가 나의 서비스명

INI 파일에

```
[Unit]
Description=Streamlit Address Check
After=network.target

[Service]
User=azureuser
WorkingDirectory=/home/azureuser/CoE_ADC_auto/address_check
ExecStart=/home/azureuser/CoE_ADC_auto/address_check/.venv/bin/python -m streamlit run app.py --server.port <포트번호> --server.address 0.0.0.0
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```
와 같이 작성해주고 저장하면 됨.

`sudo systemctl daemon-reload` 해준 후, `sudo -n systemctl start address_check.service` 해주면 systemd로 vscode와 ssh 사용 안 해도 서버 사용 가능함.
