## Gradio와 streamlit의 차이

-> 현재 내 프로그램의 웹 인터페이스를 고르는 중

- Gradio는 주로 Python 함수나 AI 모델을 웹 화면에서 바로 사용하게 만들 때 많이 씀.


나의 경우는 엑셀의 표 형식 데이터를 붙여 넣고 각 행마다 `금융기관명, 지점명, 주소` 를 검증해야하기 때문에 streamlit을 사용하는 것이 적합하다고 판단.
추후에 검색용 AI 챗봇도 추가적으로 설치할 예정.
