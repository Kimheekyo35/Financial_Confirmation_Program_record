## 정규화

- 지점이 제외되거나 미포함시 66점으로 점수가 낮게 나오는 문제 발생
-> '지점'과 '점' 이라는 접미사를 제거하고 나머지로 비교

```
def normalize_branch_name(name):
    if not name:
        return ""

    name = str(name).strip()

    # 공백과 일부 특수문자만 제거
    name = re.sub(r"[\s\-_/().]", "", name)

    # 반드시 긴 단어인 '지점'을 먼저 확인
    if name.endswith("지점"):
        name = name[:-2]
    elif name.endswith("점"):
        name = name[:-1]

    return name
```
